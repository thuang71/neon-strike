# NEON STRIKE

Standalone HTML5 canvas shmup. No build step, no libraries.

## Run locally

1. Download these three files into one folder:
   - `index.html`
   - `style.css`
   - `game.js`
2. Double-click `index.html` (or drag it into a browser).

## Controls

- WASD / Arrow keys: move
- Shift: dash
- Space: EMP when ready (otherwise dash)
- ESC: pause
- Auto fire

## Zip download

Use GitHub: **Code → Download ZIP**
